# Dev Note — 2026-09-14 — Compare perf, Batch 1

Rules & architecture live in [`CLAUDE.md`](../../CLAUDE.md); this note is rationale only.

## Context
Follow-up to the read-only performance audit of the compare/swipe render path.
Batch 1 implements the three cheapest, behavior-preserving render wins. Data
caching (`#1`) and pane windowing/memo (`#3`) are intentionally deferred.

## Changes

### #4 — Gate hot-path console logs
Diagnostic `console.log`/`console.warn` in the per-render / per-call hot paths now
run only when `process.env.NODE_ENV !== 'production'`. `console.error` (genuine
error paths) is left untouched.
- `lib/useRanking.ts` — module-level `RANKING_DEBUG` flag; guards all 7 logs
  inside the memo (which fires per row × per team × per render).
- `lib/useDisplayMode.ts` — removed the per-render mode log; gated the toggle log.
- `lib/useNflStats.ts` — module-level `STATS_DEBUG`; gated the fetch info/stale
  logs, kept `console.error`.
- `components/OffensePanel.tsx`, `components/DefensePanel.tsx` — gated per-render
  panel log.
- `components/DynamicComparisonRow.tsx` — gated the "unknown metric" warn and the
  ungated Steelers/Bucs ranking dump (the `process.env … === 'development'` bar
  log was already gated).
- `components/compare/CompareWorkspace.tsx` — gated the per-render workspace log.

### #2 — Make `useRanking` memo effective
Callers (`DynamicComparisonRow`, `CompactComparisonRow`) pass a fresh
`{ higherIsBetter, excludeSpecialTeams: true }` object literal each render, so the
old `useMemo` dep on `options` changed identity every render and recomputed the
O(32) scan — and, because its result objects changed, cascaded into
`useBarCalculation`. Fix: destructure the primitives at hook scope and depend on
`[allData, metricKey, targetTeamName, higherIsBetter, excludeSpecialTeams]`. No
call sites changed; ranking output identical.

### #5 — Memoize `transformAllData` results
`OffensePanel`, `DefensePanel`, `CompactPanel` called `transformAllData(...)`
directly in render (per-game math over all 32 teams, every render). Wrapped in
`useMemo` keyed by `[transformAllData, data]` (the callback identity already
tracks display mode). Single-team `transformTeamData` calls left as-is (cheap).

## Verification
- `npm run build` → exit 0, no errors (only pre-existing `no-unused-vars` warnings).
- No behavior/value changes: logs are the only removed prod output; ranking, bar
  math, and transformed data are computed identically (just memoized/gated).
